# 回答には参考元を出す
- 実質的な事実の主張には参考元を示す。分野を問わない。一次情報・公式ドキュメントを第一とし、版や日付が効くなら添える。
- 出所の種別を分ける。normative は公式/一次情報、codebase は file:line、web は URL、inferred は自分の推論や訓練知識。断定と推論を混ぜない。出所を確定できないものは「未確認」と印す。
- 版付きで正典に紐付ける技術の学習・検証は `docs-anchor` skill を使う。
- 校正する。load-bearing・非自明な事実は必ず出所を出す。自明・定型な事実は簡潔にする。意見・推論・創作は出所を求めず、そう明示する。水増しの脚注はしない。
